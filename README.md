# ⏱️ Stopwatch App

A simple stopwatch app built with React and TypeScript.

## Features

- Start / Pause timer
- Split (lap) time recording
- Reset stopwatch
- View split history with total and lap time

## Tech Stack

- React + Vite
- TypeScript
- CSS for styling
- `useState`, `useEffect`, `useRef` hooks

## Getting Started

```bash
# Clone the repo
git clone https://github.com/your-username/stopwatch-app.git
cd stopwatch-app

# Install dependencies
npm install

# Start development server
npm run dev
